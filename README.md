# Arduino LED Blinking Project

## Project Description

This project implements a basic LED blinking system using an Arduino Uno. 
The built-in LED connected to digital pin 13 is switched ON and OFF at 
one-second intervals.

## Hardware Used

- Arduino Uno
- Built-in LED
- USB Cable

## Software Used

- Arduino IDE
- C/C++ Arduino programming

## Working Principle

The Arduino configures digital pin 13 as an output pin.

The LED is:
1. Turned ON for 1 second.
2. Turned OFF for 1 second.
3. The process repeats continuously.

## Code

The main program is available in:

`led_blinking.ino`

## Expected Output

The Arduino built-in LED continuously blinks with:

- ON time: 1 second
- OFF time: 1 second
